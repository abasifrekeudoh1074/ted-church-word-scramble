# ✝️ Church Word Scramble Game

An interactive and fun word scramble game created for our Church Program.

Players are given 13 minutes to unscramble Bible and Church-related words while listening to soft background music.

### 🎮 How to Play
1. Enter your full name.
2. Click Start Game.
3. Unscramble the given words.
4. Submit your answers before the timer runs out.

### ✨ Features
- 13-minute countdown timer.
- Background worship music (Oceans).
- Auto-scoring system.
- Feedback and star rating after game.
- Works on both phone and laptop.

### 🛠 Built With
- Python
- Streamlit
